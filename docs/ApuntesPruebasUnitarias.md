Para hacer una prueba unitaria, en el mismo código a probar hay que escrbir
la función que hará el test y indicarla con @TEST

separar los códigos de pruebas en:

- Given: datos que damos de prueba
- When: ejecutar el proceso
- Then: resultado esperado

Para ejecutar la prueba unitaria a la izquierda del nombre de la función aparece opción para ejecutar
